# UI/UX Specification

## Direction

The CRM is a quiet operational room inside AKARI House: premium, private, fast and focused. It uses the AKARI pink and yellow sparingly against a dark workspace.

## Core layout

- Fixed 244px desktop sidebar, collapsible on mobile
- Sticky command bar with search, quick-create and privacy controls
- Moderate 26â€“30px page titles
- Solid surfaces, subtle borders and equal spacing
- Table, board, card, calendar and record-drawer patterns

## Signature interactions

- `Ctrl/Cmd + K` command palette
- Universal quick-create menu
- Record drawer that preserves table or board context
- Screen-share mode hiding financial values
- Task completion directly where the task appears
- Dashboard KPI cards opening their source records
- Opportunity stage movement with qualification requirements

## Mobile

- Bottom navigation: Home, My Day, Pipeline, More
- Tables become list cards in later implementation
- No hover-only actions
- Primary daily actions remain one tap away

## Design rules

- No glassmorphism or neon SaaS gradients
- No oversized headings
- No excessive anime artwork in operational screens
- No decorative charts without a linked action
- No duplicate lead/client records
- Finance remains permission-controlled
